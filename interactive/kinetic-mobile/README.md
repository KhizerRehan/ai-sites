# Still / Move

A small interactive Three.js mobile studio. Choose a composition, color palette and finish; adjust the breeze, drag to rotate, or let the sculpture drift.

## Run locally

From this directory run `python3 -m http.server 8000`, then open <http://localhost:8000>. Three.js and fonts load from a CDN, so an internet connection is required. Drag on the sculpture with a mouse or touch; use the workbench controls to compose your mobile.
