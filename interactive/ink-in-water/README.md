# Chroma — Ink in Water

A quiet, interactive Three.js colour study. Click or drag in the water to release pigment; choose an ink, vary the current and drop size, pause time, or clear the vessel. The vessel also accepts Enter or Space to release a drop from the keyboard.

Run from this directory with a local static server:

```sh
python3 -m http.server 8000
```

Open <http://localhost:8000>. Three.js and typefaces load from public CDNs, so an internet connection is required.
