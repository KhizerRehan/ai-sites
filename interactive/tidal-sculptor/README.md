# Tidal Sculptor

A small Three.js ocean sandbox. Raise, carve, and soften islands, change the tide and light, or generate a new archipelago.

Run a local web server in this directory, for example `python3 -m http.server 8000`, and open `http://localhost:8000`. Three.js and the optional typefaces load from CDNs, so an internet connection is required. Drag or touch the ocean to sculpt; the controls are also keyboard accessible.
