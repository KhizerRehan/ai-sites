# Afterglow — Liquid Light Lab

A retro Three.js lava lamp to customize and watch. Choose a potion, change heat and flow, switch the light, or shake the lamp. Drag the scene to rotate it.

Run from this directory with:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000 in a modern browser. Three.js and typefaces are loaded from CDNs, so an internet connection is required.
