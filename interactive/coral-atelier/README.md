# Coral Atelier

An interactive miniature reef built with Three.js. Choose a coral shape, pigment and growth size, then tap the sandy ocean floor to plant. Drag to rotate the reef. Use the surprise, undo, clear and light controls to tend your world.

## Run locally

From this directory, start a static server:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. An internet connection is required for the Three.js module and optional Google Fonts.
