# Roller Club — Marble Run Workshop

A little Three.js marble run playground. Choose one of three tracks, set the pace, pick a marble color and drop as many as you like. Drag the scene to rotate it; use touch or a mouse. Clear the track to start fresh.

Run locally from this folder:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. Three.js and the typefaces load from public CDNs, so an internet connection is required.
