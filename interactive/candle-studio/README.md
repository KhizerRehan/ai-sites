# Still Flame — Candle Studio

A quiet, interactive Three.js candle workshop. Choose a vessel and wax, pour the candle, then light it and adjust its glow. Drag the scene to turn your creation; use **Start again** to reset it.

## Run locally

From this directory, start any static server, for example:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. Three.js and fonts load from CDNs, so an internet connection is required. Controls support pointer, touch, and keyboard interaction.
