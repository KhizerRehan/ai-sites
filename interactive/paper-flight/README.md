# Paper Flight

A small, open-ended paper airplane flight through a dreamy sky. Move the pointer or use the arrow keys to steer through rings; adjust the wind or launch again whenever you like. Touch works by tapping and dragging on the sky.

Run a local web server from this directory, for example:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. Three.js and the typefaces load from public CDNs, so an internet connection is required.
