# Komorebi — Bonsai Laboratory

A quiet Three.js bonsai studio. Grow a tree, change its branch character, foliage and vessel, or generate another tree. Drag the scene to rotate it and use Reset view to return to the front.

Run from this directory with a local web server, for example:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. Three.js and fonts load from CDNs, so an internet connection is required.
