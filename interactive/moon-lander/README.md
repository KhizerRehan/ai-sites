# Soft Landing

A small Three.js lunar landing game. Guide the lander onto the glowing pad with a gentle vertical speed, low sideways speed, and an upright ship.

Run a local server in this directory:

```sh
python3 -m http.server 8000
```

Visit `http://localhost:8000`. Use left/right arrow keys (or A/D) to rotate and up arrow (or W/space) for thrust. On a touch device, hold the on-screen controls. Choose **New mission** to reset. Three.js and fonts load from public CDNs, so an internet connection is required.
