# Little Jurassic — Creative Brief

> Reconstructed from the built site on 2026-11-27. The original prompt was not saved.

Create a distinctive, gentle single-page website for **Little Jurassic**, a fictional dinosaur discovery world for young children. It should evoke a favourite picture book: friendly giants, soft jungle greens and the pride of naming a dinosaur correctly.

## Art direction

Use deep forest green (#173b35, #204e40), muted sage text (#627b71), warm cream (#f8f8ef) and pale lime (#d9eaa7), with amber stars. Set headings in Outfit and body copy in DM Sans, with tiny tracked uppercase overlines. Keep everything soft and rounded: pill buttons, white cards that lift on hover, sparkle glyphs. Use seven illustrated dinosaur images, one per species, with the Brachiosaurus as the hero picture under a dark green gradient.

## Experience

Keep the header minimal: wordmark, one anchor link and a pill tagline. The rounded hero reads "Big dinosaurs. Little explorers." with a "Let's explore" button. Below, "Meet the dinosaurs" shows seven tappable cards generated from one data list (T. rex, Triceratops, Brachiosaurus, Stegosaurus, Ankylosaurus, Velociraptor, Spinosaurus), each with a picture, name and tagline. Tapping a card opens a native modal dialog with a large picture, "Hello, name!", one simple fact and a "Listen" button that reads it aloud slowly with the browser's speech synthesis. Add a lime band inviting a "dino hunt": a five-round game in the same dialog that asks the child to find a named dinosaur among three pictures, can read the question aloud, shows five stars, meets a wrong tap with an encouraging "nice try" and another go, and awards a star before moving on. Finish with a celebration screen and "Play again". Stop any speech when the dialog closes.

Make it responsive: on phones turn the cards into compact picture-and-text rows and stack the game band. Use real buttons, a labelled close button, a live feedback line and bold focus outlines.
