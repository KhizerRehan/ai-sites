# Aurora Radio

A little arctic sky instrument built with Three.js. Drag or touch the sky to move the aurora; change its colour, glow and drift from the console. Pause, save a PNG, or turn on a quiet ambient tone.

Run a local server from this directory:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. Three.js and fonts load from CDNs, so an internet connection is required. WebGL must be enabled.
