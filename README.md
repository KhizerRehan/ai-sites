# Still / Sand

A meditative Three.js sand mandala studio. Drag or touch the sand to draw. Choose a pigment, adjust symmetry and grain flow, undo a stroke, clear the tray, or save a PNG.

Run from this directory with `python3 -m http.server 8000` and visit <http://localhost:8000>. Three.js and fonts load from public CDNs, so an internet connection is needed.
