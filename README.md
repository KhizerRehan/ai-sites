# Block Party

A playful little Three.js city builder. Select a building from the city kit and tap a plot to place or replace it. Select **Clear a plot** to remove a building, drag the scene to orbit, and change the lighting to set the mood. **Surprise me** creates a new neighborhood; **Start with a clean slate** empties it.

## Run locally

From this directory, start a static server:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. Three.js and fonts load from CDNs, so an internet connection is required. The site has no build step.
