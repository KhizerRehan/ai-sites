# Rain Room

A quiet, interactive rainy window overlooking a small Three.js city. Drag across the glass to wipe away condensation, adjust the rainfall, or change the hour of the light. The clear button wipes the entire pane; new droplets slowly gather again.

Run from this directory with a local web server, for example:

```sh
python3 -m http.server 8000
```

Open <http://localhost:8000>. Three.js and the typefaces load from CDNs, so an internet connection is required. The scene supports mouse, pen and touch.
