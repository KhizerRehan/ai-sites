# Neon Nights

A playable Three.js synthwave pinball table. Launch a ball, keep it alive with the flippers, and chase your best score. Three balls per game; scores persist in the browser.

Run a local server in this directory, for example `python3 -m http.server 8000`, then open `http://localhost:8000`. The Three.js module and fonts load from CDNs, so an internet connection is needed.

Use the on-screen controls or left/right arrow keys (also A/D) for the flippers. Press Space or the launch button to launch. Sound can be enabled from the top right.
