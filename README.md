# ORI — Origami Studio

A quiet Three.js paper-folding experience. Choose a paper color, use the fold slider or play through the sequence, and drag the scene to rotate your crane.

Run from this directory with a local static server:

```sh
python3 -m http.server 8000
```

Visit <http://localhost:8000>. An internet connection is required for the Three.js module and web fonts.
