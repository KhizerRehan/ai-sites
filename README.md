# Cloud Factory

A tiny weather workshop made with Three.js. Choose a sky, adjust the fluff, and make as many clouds as you like. Drag the scene to look around; turn on rain when the forecast calls for it.

## Run locally

From this directory, start a static server:

```sh
python3 -m http.server 8000
```

Open <http://localhost:8000>. Three.js and the optional web fonts load from CDNs, so an internet connection is required. The scene works with mouse, touch, and keyboard-accessible controls.
