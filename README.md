# Wilderwing — Butterfly Sanctuary

A little Three.js meadow for growing flowers and watching butterflies.

Run a local static server from this directory, for example:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. An internet connection is needed for Three.js and fonts. Drag the meadow to orbit; tap it to plant the selected flower. Use the journal to change the time of day or release more butterflies, and “Begin again” to reset the garden.
