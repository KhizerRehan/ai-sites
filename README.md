# Grotto — Crystal Cavern

A small, jewel-toned Three.js crystal-growing experience. Select a mineral, adjust its growth, change the cavern light, and grow a new randomized cluster. Drag the scene to rotate it.

Run a local web server from this directory, for example:

```sh
python3 -m http.server 8000
```

Visit <http://localhost:8000>. Three.js and the typefaces are loaded from CDNs, so an internet connection is required.
