# Snowfall — Snow Globe Studio

A little interactive Three.js snow globe. Choose a miniature scene and light, adjust the snowfall, drag to turn the globe, and shake it to stir the snow.

Run from this directory with a local web server:

```sh
python3 -m http.server 8000
```

Open <http://localhost:8000>. Three.js and fonts load from CDNs, so an internet connection is required. Mouse, touch, and keyboard-accessible controls are supported.
