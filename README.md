# Planet Forge

A cosmic planet-making instrument built with Three.js. Pick a world, reshape its terrain, change its atmosphere and spin, or add a ring system. Drag the planet to explore; scroll to zoom. “Surprise me” generates a fresh variation.

## Run locally

From this directory, run `python3 -m http.server 8000`, then visit http://localhost:8000. An internet connection is required for the Three.js module and Google Fonts. A modern browser with WebGL is required.
