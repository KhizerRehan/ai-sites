# FUTURE GARDEN — Creative brief

Build a fictional speculative urban gardening concept with a distinctive, optimistic ecological identity. Imagine a field station for the near future, where the city is a habitat to be tended rather than an obstacle to nature.

## Art direction

Use vivid acid green against deep forest ink, chrome, optical white, fine technical lines, large condensed typography, and editorial botanical photography. The interface should feel like an experimental design object: oversized type, asymmetric compositions, a plant specimen suspended inside a metallic orbital frame, diagrammatic labels, and purposeful motion. Avoid standard SaaS cards, generic gradients, and fake metrics. Use rich image treatments and an expansive editorial rhythm.

## Visitor journey

Lead with a striking manifesto and a clear invitation to design a small garden. Explain the fictional project through three principles. Include a functional interactive garden planner in which visitors select a space and sunlight level, then receive an illustrative plant combination with useful descriptions. Add a visual editorial section about rewilding the city and a closing invitation. Make the concept and all suggestions explicitly illustrative, not live horticultural advice. Do not imply a real organization or active sign-up.

## Interaction and craft

The planner should respond immediately to the selected choices and provide a reset. Make all controls keyboard accessible and clearly indicate selected states. Build responsive layouts for small screens; respect reduced motion, use meaningful alt text and semantic markup, and keep text readable. Use a compact static implementation with no external backend. Create a complete polished site, not a mockup.
