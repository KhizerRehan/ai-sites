# Small Hours — Creative Brief

> Reconstructed from the built site on 2026-11-27. The original prompt was not saved.

Create a distinctive, hushed single-page website for **Small Hours**, a fictional late-night bookshop for the sleepless and the curious. It should evoke a single lit window on a dark street and the comfort of one more chapter.

## Art direction

Use midnight navy (#0a1526, #111f32), warm paper (#f1e8d7) and lamplight gold (#e9ae5a). Set headlines in Playfair Display at regular weight with tight tracking and italic emphasis; set body copy in DM Sans with small uppercase labels in gold. Build the hero as a CSS night scene: a starry gradient sky, a glowing moon, and a building with three amber windows above a shopfront with a "SMALL HOURS" sign, a lit window of striped book spines and a green door. Book covers are flat colour blocks with typographic titles only. Use outline pills and underlined links; keep motion to smooth scrolling.

## Experience

Overlay a thin header on the hero: a serif wordmark, two links and a "Come by tonight" pill. The full-height hero reads "For the still awake." with a link to the shelf. Follow with a paper-coloured story section, "Some stories are best read after dark." Build "The night shelf": mood filter pills (All moods, For wandering, For wondering, For quiet) that show or hide four imagined books, each with cover, title, invented author and one-line description, and a note that the collection is fictional. Add a gold visit section, "We saved you a seat.", with a "Say hello" email link to a placeholder address and rows for hours and a vague location, stating that this is a fictional bookshop concept. Close with a simple footer.

Use semantic HTML, pressed-state filter buttons in a labelled group, a decorative scene hidden from assistive technology, a book grid that drops from four columns to two, and layouts that stack below 800px.
