# Meridian Maps — Creative Brief

> Reconstructed from the built site on 2026-11-27. The original prompt was not saved.

Create a distinctive, refined and quietly romantic website for **Meridian Maps**, a fictional independent cartography studio and atlas of imagined places. It should evoke an old chart room: parchment, fine ink lines and compass roses.

## Art direction

Use deep teal-navy ink (#122f39), parchment (#efe7cf), pale cream (#f8f4e7), burnt orange (#d55e32) as the single accent and soft sea-green fills behind the maps. Set headlines in Libre Caslon Display at large sizes with tight tracking, and use DM Sans for body text, small uppercase eyebrows led by an orange asterisk, and outlined rectangular buttons. Rule the page like an atlas plate, with 1px ink borders between and inside sections. All imagery is inline SVG: an archipelago with nested contour lines, a wave-patterned sea, serif lettering and a compass rose. Keep the page still, without animation.

## Experience

Start with a ruled header (wordmark, anchor links, an outlined button) and a split hero: the headline "For the beautifully lost." with one orange italic word, a paragraph and a button on the left; the large map of Elsewhere on the right. Add a studio note with a large serif quotation and a paragraph saying the studio is imaginary. Build the atlas as one bordered two-column panel: three place buttons (The Elsewhere Isles, The Mosslight Vale, The Amber Coast) update a title and description in a live region and change the name lettered on the island map and its corner tag. Continue with a dark "craft" section beside a compass drawing, then a contact section whose button is a mail link to a placeholder address, with a fictional-concept note.

Make it responsive with breakpoints near 850px and 480px: stack columns and hide nav links except the button. Describe each illustration, expose pressed states and give place buttons a visible focus outline.
