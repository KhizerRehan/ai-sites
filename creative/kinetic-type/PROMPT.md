# OFF REGISTER — Creative Brief

> Reconstructed from the built site on 2026-11-27. The original prompt was not saved.

Create a distinctive, noisy and typographic website for **OFF REGISTER**, a fictional three-day festival celebrating letters in motion, set in London on October 16—18, 2027. It should evoke a misprinted gig poster: loud and slightly crooked.

## Art direction

Use near-black ink (#171717), warm paper (#f4f0e5), acid yellow-green (#d9ff00), hot pink (#fe4e93) and electric violet-blue (#5536f3). Set the giant wordmark and headlines in Archivo Black with extreme negative tracking, body text in Space Grotesk, small uppercase labels in DM Mono, and one italic Georgia word as an accent. Type is the only imagery: the second line of the hero wordmark is pink, outlined in ink, slightly rotated and given a hard offset shadow, as if printed off register. Add a slowly rotating acid starburst, a round blue sticker, hard box shadows and a marquee ticker.

## Experience

Open with a bordered navigation bar (logo, anchor links, a solid button) and a hero with two mono caption blocks (what it is; place, "Fictional event" and dates), the wordmark and a one-line description. Follow with a dark slogan ticker and a short introduction. Add an acid-coloured lineup of four schedule rows, each with time, title and format, and a blue "type lab" where a pink card holds a large text input (prefilled, limited to 18 characters) and three toggle buttons, LOUD, FANCY and MONO, that restyle the typed sample in a bold sans, an italic serif or a monospace. Close with a "See you there" section whose button is a mail link to a placeholder address, plus a line saying this is a concept, not an actual event.

Make it responsive: below 700px stack the grids and hide nav links except the button. Label the input, expose pressed states, and collapse animation for reduced-motion users.
