# Sunday Supper — Creative Brief

> Reconstructed from the built site on 2026-11-27. The original prompt was not saved.

Create a distinctive, warm-hearted single-page website for **Sunday Supper**, a fictional neighbourhood supper club for long tables and good company. It should evoke red-sauce Sundays, mismatched chairs and plates passed across the table.

## Art direction

Use tomato red (#bc3427), buttery cream (#fff5dd), brown ink (#3c2520), olive green (#526c3c) and a soft pink (#e9a394). Set big, tight headlines in DM Serif Display with red italic emphasis, and use bold uppercase DM Sans for labels and navigation. The hero sits on a gingham-check pattern drawn with CSS gradients, beside a tilted inline SVG illustration of a plate of pasta, tomatoes and basil and a rotated dashed circular stamp. Use pill buttons that tilt on hover and a slowly scrolling red marquee. No photography.

## Experience

Start with a red banner announcing "a little imaginary club", then a header with the stacked wordmark, anchor links and a "Come on in" pill. After the hero ("Pull up a chair.") and the marquee, tell the story in a two-column intro. Follow with a green sample-menu section listing four sharing dishes with course labels and a note that this is a fictional concept, not a live restaurant. Then a split "gather" section pairing an SVG illustration of a hand-lettered dinner invitation on red with copy on pink, and a "Good to know" FAQ built from four native disclosure elements with plus/minus markers, one of which explains there are no reservations. Close with a red footer and a giant "Until we eat again." No booking form.

Make it responsive: below tablet width swap the links for a hamburger button that opens a stacked menu, changes to a close symbol and collapses when a link is chosen; stack all grids and stop the marquee. Give the illustrations text alternatives and remove animation and transitions under reduced motion.
