# Static Garden — Creative Brief

> Reconstructed from the built site on 2026-11-27. The original prompt was not saved.

Create a distinctive, playful single-page website for **Static Garden**, a fictional instrument studio making synthesizers for curious people. It should evoke a modular synth humming on a workbench and the urge to turn a dial just to hear what happens.

## Art direction

Use near-black ink (#10120f) with an acid lime (#c6ff39), pale paper (#e6e8df), muted grey-green (#a4aa98) and olive hairlines (#444c3b). Set oversized uppercase headlines in Space Grotesk and all labels in uppercase DM Mono. The hero pairs a three-line "MAKE GOOD NOISE." with a CSS-drawn synth module: hard offset shadow, an oscilloscope screen with scanlines and a glowing SVG waveform, four knobs and a row of jacks. Use square corners, thin rules, asterisk glyphs and flat blocks of lime; no photography.

## Experience

Open with a lime announcement strip and a header ending in an outlined "Play the synth" link. After the hero, add a three-phrase ticker row and a short philosophy statement. The centrepiece is a lime section holding "The Seedling", a working browser instrument: a waveform select (sine, triangle, square, saw), an output-level slider with a live percentage, and an eight-key on-screen keyboard from C4 to C5 mapped to the A S D F G H J K keys. Use the Web Audio API so a note sounds only while its key is held, by pointer, Space or Enter, or the computer keyboard; allow several notes at once, soften each note's start and end, apply level changes live, and show a status readout. Follow with three module ideas in a ruled grid, a pale manifesto with a "Play again" link, and a footer with a giant lime wordmark, labelled a fictional concept.

Make it responsive down to small phones, hiding secondary navigation and stacking the grids. Label every key for screen readers and announce the status politely.
